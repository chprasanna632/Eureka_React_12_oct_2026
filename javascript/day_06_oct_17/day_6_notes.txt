Arrow Function 
===============
-anonymous
-not hoisted
-reduced code
-function keyword is not used
-function body is optional (1 line of code)
-return is optional (1 line of code)


HigherOrder Function: A function that takes another functions as argument.
CallBack Function : A Function that's passed as argument to another function

-In this example map() is HigherOrder & incrementBy5 is callback function

    function incrementBy5(ele){
        return ele+5;
    }
    let result1 = arr.map(incrementBy5);


How 'this' works with Arrow Function 
=====================================
-in Arrow function 'this' value is decided from the Lexical Scope
-Lexical Scope : the scope where arrow function is written




Closure
========
-A closure is a concept where a function remembers variables from its outer scope even after the outer function has finished executing.

-When the outer function execution completes, we would expect all its variables to be no longer accessible. However, if the inner function uses variables from the outer function, those variables remain accessible.

-When an inner function accesses any data from the outer function, a 'closure' scope gets attached to the inner function.
 hence inner function can access outer function data.

Note: Closure scope is seen only for inner functions and not for outer functions
      Closure Scope will be attached to inner function only if the inner function is using outer function data
