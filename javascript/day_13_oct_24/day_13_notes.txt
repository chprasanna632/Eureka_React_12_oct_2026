Set
===
-A Set is a Javascript Object that stores unique values.
-Set can be iterated using loop,forEach()
-Set Properties:
	No Duplicate Values
	Maintains Insertion Order
	Can store any data type
	No indexing
-When To Use Set:
	Remove Duplicates easily
	Fast lookups (O(1))



object vs map
=============
1. object keys must be strings, where as map keys can be of any type.
2. we can get the size of a Map easily.  ex: map.size
   for object size has to be calculated manually. ex: Object.keys(obj).length
3.The iteration of maps is in insertion order of the elements
4.Objects are not inherently iterable (Object.keys() is slow), Maps are iterable.


Map
===
-Map is a collection that stores data in key-value format.
-Map Properties:
	Keys can be of any datatype
	Keys are unique
	Insertion Order is preserved
Why Do We need Map:
	When keys are not strings
	For Dynamic key-value data
	Faster




Promise
=======
-A promise is an object that holds the future value of an asynchronous operation.
-A Promise object represents a value that is not available now, but will be resolved/available at some point in the future.
-Promise object can have different states:- pending, resolved/fulfilled, rejected.
ex:-if we request some data from a server, promise promises us to get that data that we can use in the future. 


ex: 
// fetch() returns a promise Object
let usersPromise= fetch('https://jsonplaceholder.typicode.com/users');
console.log(usersPromise);
