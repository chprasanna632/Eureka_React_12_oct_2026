-Easier to maintain, Reusable

ESM imports & exports
=====================
-Default import:
  import DefaultMember from 'src/my_lib';
-Named imports:
  import { name1, name2 } from 'src/my_lib';
-Combining a default import with named imports
  import DefaultMember, { name1, name2 } from 'src/my_lib';
  import React, { Component } from 'react';



Dynamic Import
==============
-A Dyncamic import allows us to import a module at runtime instrad of at the top of the file.
-Module is loaded only when needed
-Improve the performance

Static Import
	import mathObj from "./math.js";  

Dynamic Import:
	const mathObj = await import('./math.js')
