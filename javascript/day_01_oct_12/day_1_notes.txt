Web Development
===============
-Developing Websites (https://www.amazon.in/)
 

1. FrontEnd : User Interface (Look & Feel) 
              Presentation layer
         HTML : Content (button, div, paragraph, image, table, list, form)
         CSS :  Styling (Border, background, color, margin, padding)
         Bootstrap : CSS Library (pre-defined css classes)
         Javascript : Behaviour of a webpage, dynamic content, Interactivity
         React/Angular/Vue : Javascript frameworks (RAD, CLI, build , deploy)

2. BackEnd : Business Layer, Build REST APIs (https://fakestoreapi.com/products)
            Java / .net / Python / PHP / Go / NodeJS

3. DataBase :  Holds the Application data

CSS
====
1. inline CSS 
   style attribute, not re-usable , repeat in each element
2. internal CSS
   <style></style>
3. external CSS
   a. create a separate .css file
   b. link that css file to html file using <link rel>



Bootstrap
=========
-CSS Library
-Maintained by Twitter
-Bootstrap 5 is the latest version
-Official doc link:
  https://getbootstrap.com

How to use Bootstrap in HTML file: (add CDN link)
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">
